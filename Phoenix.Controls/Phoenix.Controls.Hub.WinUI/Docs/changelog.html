Phoenix Controls

Changelog

v0.11.8
2026-05-24
Fixed
  • Architect now reliably opens its graph files (the canvas no longer aborts with an internal error on dashed pin overlays).
  • Hub stops flooding the system log with shutdown errors when it closes.
  • Architect's script files load cleanly while Hub is mid-save, instead of failing with "file in use".
Gone
  • Architect no longer auto-reopens the last file on launch — it starts at the welcome screen. Use File → Recent to reopen.
v0.11.7
2026-05-23
Fixed
  • Architect nodes now show their input and output bubbles again.
  • The vertical bar that hung below Architect's Inspector panel is gone.
v0.11.6
Bubbles & Inspector Trim
2026-05-23
Fixed
  • Architect socket bubbles are visible again — every pin paints its shape on the body edge.
  • The empty horizontal strip at the top of the Inspector panel is gone when nothing is selected.
  • The Inspector header title reads at a proper size and contrast instead of a faint sliver.
v0.11.5
Canvas Polish
2026-05-23
Fixed
  • Architect nodes paint above their wires again — pipes no longer cover node titles or pin labels.
  • Socket bubbles sit on the node's outer border, straddling the edge for a cleaner pin-to-wire connection.
  • Wires on multi-line Template / Script / Payload pills stay glued to their pin instead of drifting away.
  • Variable-type bubbles use a simpler shape palette — number pins (Int and Float) all read as circles.
  • The Inspector panel is visible by default; its show / hide chevron now lives on the Inspector header.
Gone
  • The Inspector toggle button in the Library header — use the chevron on the Inspector itself.
v0.11.4
Architect Canvas Polish
2026-05-22
Fixed
  • Architect's rail footer buttons show their icons (+ / − / ✎ / × / Aa) instead of empty boxes.
  • Wires now meet their sockets exactly — pipes and bubbles line up on both axes.
  • Dragging nodes or frames in Architect is noticeably smoother — large graphs no longer stutter.
  • Clicking inside a frame on the Architect canvas clears the selection like clicking the empty canvas does, and drag-selecting can now start from inside a frame too.
  • Architect's Inspector lives on the right edge again instead of popping out as a separate window.
v0.11.3
Test Coverage
2026-05-22
Internal release. Adds integration test coverage across the suite (bus loopback, scheduler cron + DST, updater download resume, exporter string round-trip, stress / durability soak). No user-visible changes since v0.11.2.
v0.11.2
Canvas Comfort
2026-05-22
Fixed
  • Architect's canvas drags smoothly on busy graphs.
  • Ctrl+Z, Ctrl+S, and other menu shortcuts work from anywhere, not just with the menu open.
  • Frames only move when grabbed by their visible header — body clicks just select.
  • Frame titles are larger and brighter — no more invisible labels.
  • Welcome card no longer crashes Architect on first open.
v0.11.1
Crash Hotfix
2026-05-22
Fixed
  • Architect's pillar tab opens again instead of crashing on click.
  • Chat no longer crashes Hub on every incoming message.
v0.11.0
Architect Chrome Refresh
2026-05-22
New
  • Inspector opens in its own floating window — move it where you want, including a second monitor.
  • LeftRail collapses to a thin strip with a chevron when you need more canvas room.
  • Mini-map navigator in the bottom-right of Architect — click to jump, drag the gold box to pan.
  • Welcome card lists Starter / Intermediate / Advanced example graphs — click to open one.
  • Help → Keyboard Shortcuts dialog shows every chord Architect knows.
Fixed
  • Renaming a node on the canvas no longer breaks its script binding — the typed name is now display-only.
  • Frames carry their contained nodes when you drag them.
  • Ctrl chord shortcuts work on Dvorak layouts.
  • Undo now covers databank cell edits and LeftRail renames.
  • Dropping a .phx file opens the matching .phxg instead of erroring.
v0.10.8
Polish
2026-05-22
Fixed
  • Architect opens .phxg graphs again.
  • System Log scrolls with the mouse wheel.
  • System Log lets you drag across rows to select several entries at once.
  • Hub panel headers now line up with their right-side buttons and chips.
  • Hub panel headers stand out clearly from the background instead of blending into it.
  • Pop-out panel windows now wear a Phoenix-branded title bar instead of the plain Windows one.
v0.10.7
2026-05-22
Fixed
  • Hub closes cleanly — no more shutdown hang where the process stayed alive after the window closed.
  • Hub starts noticeably faster — the first-launch database setup no longer stalls for around half a minute.
  • Pop-out windows now have a full title bar with minimize, maximize, and close buttons.
  • Mouse wheel scrolls in the System Log and Scripts panels.
  • Architect shows a clear error in the status bar when a graph file fails to load (previously opened a blank canvas with no feedback).
v0.10.6
2026-05-20
New
  • Visualist: edit a widget's position, size, and preset directly on the canvas as click-to-edit pills (no longer inspector-only).
Fixed
  • Scripts round-trip tabs, quotes, and Unicode characters correctly between Architect graphs and exported scripts.
  • Scheduled scripts no longer skip or duplicate firings around daylight-savings transitions.
  • Hub's title bar drag region works correctly; LiveFeed and Chat panels stay responsive after pop-out and re-dock.
  • Updater resumes interrupted downloads instead of restarting from zero; stale staging files clean up automatically.
  • OBS overlay pages render smoother under heavy chat or alert traffic, and are now properly transparent in OBS browser sources.
v0.10.5
2026-05-20
New
  • Changelog rewritten in a new format with a styled HTML version at the repo root.
v0.10.4
2026-05-20
Fixed
  • Released builds now show "RELEASE" in the title bar (previously showed "DEV").
v0.10.3
2026-05-20
Fixed
  • Hub closes cleanly — no more shutdown hang.
  • Architect loads existing graphs again (the silent empty-canvas failure is gone).
  • Restored proper character encoding in Hub's interface text — dashes, ellipses, and accented characters render correctly.
  • System Log supports Shift-click and Ctrl-click for multi-row selection.
  • Pop-out windows no longer overlap their source panel's title bar.
v0.10.2
2026-05-19
Fixed
  • System Log: text selection restored in message rows.
  • Architect's Databank tab shows a placeholder if it fails to load (previously crashed the pillar).
  • Hub's hint strip, search boxes, and settings labels render correctly on UTF-8 systems.
  • Streamer.bot disconnect messages are rate-limited — only the first one logs until reconnect.
  • Chat input has its own surface; the SEND button now reads as paired with the textbox.
Gone
  • The duplicate version number in the status strip (the title bar's stamp is canonical).
v0.10.1
2026-05-19
Fixed
  • Hub starts cleanly on systems where high-contrast detection fails (previously showed "Hub startup failed").
v0.10.0
Redesign
2026-05-19
New
  • Top-to-bottom Hub redesign — forged charcoal background, brass and ember accents, new typography (Cormorant Garamond, Inter, JetBrains Mono).
  • Architect multi-window mode — open multiple graphs side by side; copy and paste nodes between them.
  • Chat panel colours names by role (broadcaster, mod, VIP, subscriber, regular) with a role badge prefix.
  • Visualist: live preview thumbnails on widget nodes.
  • Visualist: "Copy as Architect snippet" command for visual triggers.
Fixed
  • System Log: multi-row selection, smoother auto-scroll during streaming, per-level filter.
  • OBS overlays: stale frames are dropped instead of queued when the bus falls behind.
  • Architect canvas: smoother pan and zoom on large graphs.
  • Updater: stops retrying on 401, 403, and 404 responses from GitHub.
  • Ctrl+Z and Ctrl+Y work on all keyboard layouts (QWERTZ fix).
Gone
  • Tabbed multi-graph view in Architect (replaced by multi-window mode).
